# Sync

Target location for sync-facing contracts and adapters.

## Folders

- `Core/` - sync roles, sync module ids, and sync component contracts.
- `Config/` - sync configuration assets.
- `Snapshot/` - snapshot contracts, snapshot data, and snapshot buffering.
- `Timing/` - fixed tick driving utilities.
- `Transform/` - transform snapshot capture, receive, and interpolation runtime.
- `Prediction/` - prediction and replay entry contracts.
- `Animation/` - animation snapshot data and sync entry.
