# 02: 流程核只拆名册与菜单

**What to build:** 玩家离开或房主解散后，玩法对象已经随对局流程态拆掉；流程核只负责取消尚未完成的加入、拆除名册、加载菜单入口场景。点了加入但还没被接受就离开时，只拆掉那条连接，菜单干净，不会留下名册或玩法对象。

**Blocked by:** 01: 对局态接线，删除粘合类型

**Status:** resolved

- [x] 对局里离开或解散：对局态离开后无关卡控制、无模拟核、无本机 pawn；流程核拆除名册并回到菜单入口
- [x] 流程核拆除路径不再兼拆玩法对象（不二次注销关卡控制/模拟核/本机 pawn）
- [x] 加入尚未被接受时离开：流程仍为菜单，无连接残留，无名册，无玩法对象
- [x] 名册结束（房主解散）仍把流程切到菜单，随后同一套对局态拆除 + 流程核拆名册
- [x] 测试走流程核公开意图（离开、取消加入），不测状态机内部、不测场景 YAML

## Answer

对局态 `Exit` 拆除玩法对象。流程核 `TearDownSession` 只解加入 Handler、拆名册、加载菜单；加入进行中则只停客户端连接。`LeaveSession` / 名册结束仍切到菜单，从而先走对局态离开。
