# 03: 加入未接受前没有对局，接受后接管同一条连接

**What to build:** 加入方点加入后仍在菜单：只有一条尚未入座的连接，没有名册对象、也没有玩法粘合点。失败、拒绝或取消后拆掉客户端网络，菜单干净。被接受后才有名册对象，接管同一条连接（不重连），再进入对局并登记玩法粘合点。不另做短命加入类型；未再使用的「加入中」流程态不留在可编译路径里。

**Blocked by:** 01: 房间并进名册对象，玩法粘合点不接管名册

**Status:** ready-for-agent

- [ ] 点加入后流程仍为菜单，没有名册对象、没有玩法粘合点
- [ ] 连接失败、被拒绝或取消加入后：仍为菜单，无名册对象，客户端网络已拆
- [ ] 被接受后才有名册对象与名册（含自己），且仍是加入过程中的那条连接
- [ ] 本机玩与开多人不走客户端连接路径，仍是立刻创建名册对象
- [ ] 没有可停留的加入中流程态
- [ ] 测试走加入已决与名册对象是否存在，不测真实传输握手细节
