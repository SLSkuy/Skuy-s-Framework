# 02: 加入方中途入座

**What to build:** 加入方点加入后先连接；被接受前没有房间。接受后拿到自己的玩家身份、房主身份、完整名册，且对局已开始；本进程才建房间并入座，再切关卡、挂客户端核、不生成 pawn。双方名册一致。拒绝或连接失败则回到菜单且无房间。

**Blocked by:** 01 菜单开战进关（本机房与房主）

**Status:** ready-for-agent

- [ ] 加入请求不得用对方自报的传输身份作为名册键；玩家身份由房主分配
- [ ] 加入响应包含：是否接受、自己的玩家身份、房主玩家身份、完整名册、对局已开始（开听之后为真）
- [ ] 接受前加入方没有房间对象；接受后房间名册含自己与已在席者
- [ ] 房主名册与加入方名册一致
- [ ] 加入方切关卡后挂客户端核，本阶段不 spawn
- [ ] 加入方不必等房主 pawn 生成完毕即可入座进关
- [ ] 拒绝、连接失败或房间不存在时回到菜单，拆掉客户端网络，无活动房间
- [ ] 测试通过向战局管理器注入加入请求/响应对外断言名册与对局已提交；UI 仍只对流程核心发意图
