# 01: 菜单开战进关（本机房与房主）

**What to build:** 玩家从菜单点本机玩或开多人后，进入关卡并开始对局：本机入座、只生成本机一枚 pawn、常驻 HUD 可以解散并回到菜单。本机房容量为 1 且不接远端；多人房主容量为 4 并开听，一点开就视为对局已开始。玩家路径不再停在大厅。关卡只承载几何，不启动第二套进程壳。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 本机玩：建本机房、切关卡后再开战，名册只有本机玩家，生成恰好一枚 pawn，实体身份等于玩家身份
- [x] 本机房容量为 1，尝试让远端入座失败
- [x] 开多人：本机入座、开听、对局在协议上已开始，切关卡后再开战，只生成本机一枚 pawn
- [x] 开多人房容量为 4
- [x] 玩家可观察的流程只有菜单与对局，点入口后不会停在大厅
- [x] 常驻 HUD 能看到名册，解散后卸关卡、无活动房间、回到菜单
- [x] 关卡场景不再带第二套进程壳；回菜单后仍只有一份进程壳
- [x] 测试走战局管理器会话 API（本机建房、开多人房、入座拒绝、开战），不测核内部步进

## Answer

本机玩与开多人都是菜单直接提交对局：先切关卡再开战，只生成本机一枚 pawn（实体身份等于玩家身份）。本机房容量 1 且拒远端；房主容量 4 并开听。大厅只作内部切关间隙。常驻 HUD 可解散：卸关卡、拆房间、回菜单。关卡不再带第二套进程壳。会话 API 的 EditMode 测试覆盖建房、容量与开战提交。
