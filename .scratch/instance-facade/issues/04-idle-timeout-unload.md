# 04: 借出为零后 30 秒卸预制体句柄

**What to build:** 某一资源位置没有借出实例后开始空闲计时；期间再 Instantiate 则清零。满 30 秒（全局同一时长）销毁空闲实例并释放该位置的预制体句柄。仍有借出时不得卸句柄。卸掉后再 Instantiate 仍能生成。

**Blocked by:** 02: 同步实例门面（内部池与快捷方式）

**Status:** ready-for-agent

- [x] 借出 > 0 时推进时间不会卸掉该位置句柄，场上实例仍可用
- [x] 全部 Release 后累计满 30 秒：空闲实例被销毁，再 Instantiate 是新生命周期而不是还池命中同一批空闲对象
- [x] 空闲计时期间再次 Instantiate 会重置超时
- [x] 所有资源位置共用 30 秒，没有按位置的超时参数
- [x] 计时走实例门面的子系统 Update；测试用喂 deltaTime，不真睡 30 秒

## Comments

- 全局空闲超时 30 秒，写在实例门面内部常量，没有按资源位置的参数。借出或未完成的 InstantiateAsync 视为该位置忙碌，不计时。
- `Update(deltaTime)` 先完成异步交付，再累加空闲时间；满 30 秒销毁该位置空闲实例并 Dispose 预制体句柄。测试用 `Update(30f)` / 分段喂时间，不断言内部字典。
