# 面板按面板名入册，窗口必须事先在册

调用方只说面板名。面板名不是资源位置；界面分组里的资源位置由分组和文件名组成，框架在入册时自己把面板名对上资源位置。

不在册的面板按面板名造出实例并入册，然后显示。框架自己入册的面板一旦隐藏，就按界面分组的空闲时间计时；时间到了先出册，再把实例还池。再次显示会重新入册。重复隐藏不把已开始的计时清零，再次显示则取消计时。别人手动入册的面板只显示和隐藏，不因空闲出册。

窗口不走这条路。窗口层拿着历史和队列，自动出册会拆掉这些引用，所以窗口必须事先在册，也不会因空闲出册。

出册只让界面离开名册。实例还池之后，资源还在不在，仍由界面分组自己的空闲规则决定，不跟出册绑在同一刻。

## 考虑过的做法

- 让调用方直接传资源位置。面板名和资源位置会变成同一个词，和「资源位置不是面板」冲突。
- 隐藏后立刻出册并还池。短时间反复打开同一块面板会反复造实例。
- 窗口也自动入册，并在空闲后出册。历史和队列里会留下已经出册的窗口。
