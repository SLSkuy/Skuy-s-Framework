# 面板和窗口都按名字入册，历史只记窗口名

调用方只说界面名。界面名不是资源位置；界面分组里的资源位置由分组和文件名组成，框架在入册时自己把界面名对上资源位置。

不在册的界面按名字造出实例并入册，然后显示。框架自己入册的界面一旦隐藏，就按界面分组的空闲时间计时；时间到了先出册，再把实例还池。再次显示会重新入册。重复隐藏不把已开始的计时清零，再次显示则取消计时。别人手动入册的界面只显示和隐藏，不因空闲出册。

窗口的历史和队列只记窗口名，不记属性。回到上一扇或轮到队列里的下一扇时，按名字再入册。排在队列里、尚未显示的窗口算作隐藏，可以出册。

弹窗强制留在最前。打开弹窗不把底下的窗口送去隐藏，底下的窗口也就不开始空闲计时。其余窗口在被盖住或关上时走这条隐藏路径。

出册只让界面离开名册。实例还池之后，资源还在不在，仍由界面分组自己的空闲规则决定，不跟出册绑在同一刻。

## 考虑过的做法

- 让调用方直接传资源位置。界面名和资源位置会变成同一个词，和「资源位置不是面板」冲突。
- 隐藏后立刻出册并还池。短时间反复打开同一块界面会反复造实例。
- 历史和队列记下窗口本身。窗口一旦出册，历史和队列里就会留下已经离开名册的窗口。
- 窗口必须事先入册，并且从不因空闲出册。窗口会一直占着实例。
