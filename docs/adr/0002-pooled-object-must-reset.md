# 进池对象必须重置

可复用对象可以再次出场，实体号本局不回收。进池的对象必须在再次出场前清掉上一场留下的状态；没有重置的对象不能进池。

## 考虑过的做法

- 在离场的调用方解开实体号。复用发生在对象池，解开却散落在每个调用方，下一次出场仍可能带着旧身份或旧运动状态。
- 允许已绑定的对象在运行时改绑实体号。同一次出场里改号会把两个实体叠在同一个对象上。
- 玩家实体不进池，离场即销毁。每次出场都是新对象，避免了旧状态，也放弃了复用。

## 后果

- 纯对象池与实例池都只接受能重置的对象。还池时重置。实例再次借出并套用这次的位置与旋转之后，再重置一次，让画面对齐这次出场。
- 实体身份在重置时解开。下一次出场用新的实体号重新绑定。
- 玩家实体重置时同时清掉上一场的运动、视角和状态。
- 未实现重置的实例在进入对象池时失败，而不是带着旧身份被借出。
