# 再次借出时先重置再摆放

实例从空闲再次借出时，先重置，再套用这一次的父节点、位置、旋转和是否激活。这一次的摆放是最终状态。

这取代 ADR 0002 里「先摆放再重置一次」的说法。重置若写回位置或显隐，后重置会盖掉这一次出场。

## 考虑过的做法

- 先摆放再重置，好让重置里的画面逻辑看见新位置。重置里常见的归零会把刚设好的位置清掉。
- 只在还池时重置，借出时不再重置。空闲期间若有人改过实例，下一次出场仍带着那次改动。

## 后果

- 还池和再次借出都会重置。借出时的重置发生在摆放之前。
- 第一次造出实例时还没有上一场状态，只摆放，不先重置。
