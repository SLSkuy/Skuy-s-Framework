# 资源就绪、场景层

资源包没准备好时不启动其余子系统。场景界面放在场景层，批量关闭界面时跳过这一层。玩法流程仍是菜单、加入、对局。资源门面仍返回 YooAsset 句柄。

## 资源就绪

包初始化、版本请求、清单加载，任何一步失败，就停在这一步，不发出资源就绪。不受支持的加载模式同样不发出就绪。`AppCore` 只在就绪之后注册其余子系统，所以失败时启动停在资源阶段。

## 场景界面

场景界面是第三种界面，不是面板，也不是窗口。它按界面名入册，放在场景层。批量关闭界面时跳过场景层。

加载用的界面是场景界面。它自己听场景 IO 的进度、完成和失败，结束时自己关上。场景激活时清掉随场景走的实例、卸未使用资源，仍留在场景 IO。

出册和还池仍跟界面分组的空闲规则走。
