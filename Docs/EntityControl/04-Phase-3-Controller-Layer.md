# Phase 3: Controller Layer

## Goal

Turn controllers into control-source orchestrators instead of behavior containers.

## Tasks

- define player controller
- define authority controller
- define replica controller
- define AI controller
- define vehicle controller
- define binding rules between controller and entity
- define drive-mode switching rules

## Success Criteria

- each control source has a clear boundary
- controllers no longer contain heavy gameplay systems
- player, authority, replica, and AI flows are independently evolvable
