# Feature Plan Index

This directory contains feature designs and implementation plans that need ongoing tracking. Each feature uses a subdirectory, and documents are named directly after the feature or purpose, for example `movement-design.md` or `network-sync-plan.md`.

Small features may use the minimal document template. Architecture, protocol, and cross-module work must use the full self-contained template. See [../../.agents/rules/Documentation.md](../../.agents/rules/Documentation.md).
